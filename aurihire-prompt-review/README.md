# AuriHire prompt review (2026-10-21)

Independent review of three production prompts for the AuriHire screening pipeline.

- `REVIEW.md`: sample walkthrough, ten ranked problems per file with quoted lines, change logs, eight regression test cases, open questions for the product owner, and separate notes on `rules.ts` and on model/effort.
- `rewrites/lib/ai/planner.md`, `rewrites/lib/ai/screener-extractor.md`, `rewrites/lib/ai/screen.md`: drop-in rewrites. Frontmatter, leading HTML comments, placeholders (same names, same counts), output field names, enum values and the planner's output contract are unchanged.

The original prompt files are not in this repository; they were supplied inline for review.
